# Catálogo de Produtos

Aplicação desenvolvida com React e Vite para exibir um catálogo de produtos com busca, paginação e integração com uma API pública.

## Funcionalidades

- Listagem de produtos em cards
- Busca por título
- Navegação por páginas
- Estados de carregamento e erro
- Interface responsiva e moderna

## Tecnologias

- React 19
- Vite
- CSS Modules
- JavaScript

## Execução

```bash
npm install
npm run dev
```

A aplicação ficará disponível em http://localhost:5173.
